# Business Model Canvas

## For future agent
This note explains the Business Model Canvas (Osterwalder and Pigneur, Business Model Generation, 2010): its nine building blocks, how it relates to the Value Proposition Canvas, and how Company Brain uses it.

## What it is
A one-page model of how an organization creates, delivers, and captures value, in nine blocks (Business Model Generation, Wiley, 2010; https://www.strategyzer.com/library/the-business-model-canvas):

```
┌──────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
│ Key          │ Key          │ Value        │ Customer     │ Customer     │
│ partnerships │ activities   │ propositions │ relationships│ segments     │
│              ├──────────────┤              ├──────────────┤              │
│              │ Key          │              │ Channels     │              │
│              │ resources    │              │              │              │
├──────────────┴──────────────┴──────┬───────┴──────────────┴──────────────┤
│ Cost structure                     │ Revenue streams                     │
└────────────────────────────────────┴─────────────────────────────────────┘
```
The right side is value creation for customers; the left side is the efficiency of delivering it.

## Relation to the Value Proposition Canvas
The [[Value Proposition Canvas]] zooms into two blocks: one customer segment and its value proposition. Business-model fit (the third fit stage) is judged on the full canvas.

## How to use it
1. Start with customer segments and value propositions; one VPC per important segment.
2. Fill the remaining blocks; mark assumptions.
3. Look for the riskiest assumption (often revenue or channels) and test it.
4. Keep alternative canvases for options you are comparing.
