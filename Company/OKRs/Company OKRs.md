# Company OKRs

## For future agent
This is the company OKR hub: annual and quarterly company objectives with key results, plus links to the generated cascade. Team objectives ladder up through `parent:` links to a company key result.

## Cascade
Generated by `brain refresh` for the current quarter and year:
```dataview
LIST FROM "Company/OKRs" WHERE type = "okr-tree" SORT file.name DESC LIMIT 4
```

## Annual objectives
```dataview
TABLE owner, status, last_checkin
FROM "Company/OKRs"
WHERE type = "objective" AND length(string(period)) = 4
SORT period DESC, file.name ASC
```

## Quarterly objectives
```dataview
TABLE period, owner, status, parent, last_checkin
FROM "Company/OKRs"
WHERE type = "objective" AND length(string(period)) > 4
SORT period DESC, file.name ASC
```

## All key results this quarter (company and teams)
```dataview
TABLE WITHOUT ID file.link AS "Objective", L.text AS "Key result", L.current AS "Current", L.target AS "Target", L.confidence AS "Confidence"
FROM "Company/OKRs" OR "Teams"
FLATTEN file.lists AS L
WHERE type = "objective" AND period = dateformat(date(today), "yyyy-'Q'q") AND L.target
SORT file.name ASC
```

## Rules
Objectives are qualitative and inspiring; key results are measurable outcomes, not tasks. Three to five objectives per level per quarter, two to four KRs each. Score 0.0 to 1.0, where 0.7 is a good result for an ambitious KR. See [[OKRs]]. Create, check in, and score with `/company-brain:okr`.
