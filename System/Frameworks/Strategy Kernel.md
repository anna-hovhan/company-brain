# Strategy Kernel

## For future agent
This note explains Richard Rumelt's strategy kernel (Good Strategy Bad Strategy, 2011): diagnosis, guiding policy, and coherent actions, the four hallmarks of bad strategy, and how Company Brain turns a kernel into objectives, projects, and decisions.

## What it is
Rumelt argues that good strategy has a simple core he calls the kernel (Good Strategy Bad Strategy, Crown Business, 2011):
1. **Diagnosis**: an explanation of what is going on, naming the critical challenge. It simplifies a messy reality into something you can act on.
2. **Guiding policy**: the overall approach chosen to deal with the challenge. It channels action in some directions and rules out others.
3. **Coherent actions**: a set of coordinated steps that carry out the policy and reinforce each other.

## Bad strategy (the four hallmarks Rumelt names)
- **Fluff**: buzzwords and restated obvious things passed off as insight.
- **Failure to face the challenge**: no diagnosis, so no way to judge the strategy.
- **Mistaking goals for strategy**: "grow 30 percent" is a wish, not a plan for how.
- **Bad strategic objectives**: a long list of things to do, or objectives that do not address the challenge.

## How to use it
1. Write the diagnosis first, with evidence and dates. If you cannot name the challenge in two sentences, keep diagnosing.
2. Choose a guiding policy and write down what it rules out.
3. List the coherent actions; check that each one supports the policy and the others. Each action becomes an annual objective, a project, or a decision.
4. Run the bad-strategy checklist on the draft.
