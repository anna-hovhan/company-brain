# Frameworks

## For future agent
This is the hub of the framework library: the theory notes behind every Company Brain template and skill. Read the relevant note before applying a framework so the output follows the method, not a loose memory of it.

| Framework | Use it for | Template | Skill |
|---|---|---|---|
| [[Strategy Kernel]] | diagnosing the challenge and choosing a guiding policy | Strategy Kernel Template | `strategy kernel` |
| [[Playing to Win]] | the five linked strategic choices | Playing to Win Template | `strategy playing-to-win` |
| [[Business Model Canvas]] | how the business creates and captures value | Business Model Canvas Template | `strategy bmc` |
| [[Value Proposition Canvas]] | customer fit per segment | Value Proposition Canvas Template | `vpc` |
| [[OKRs]] | annual, quarterly, team, and personal goals | Objective Template | `okr` |
| [[Opportunity Solution Tree]] | discovery from outcome to experiment | OST Outcome, Opportunity, Solution, Experiment Templates | `ost` |
| [[Effort-Impact Matrix]] | prioritization, with RICE | (generated) | `prioritize` |
| [[Now-Next-Later Roadmap]] | outcome-based roadmap | (board) | `roadmap` |

How they connect: [[Mission]] and [[Vision]] set direction; the kernel and Playing to Win set strategy; canvases test customer and business fit; OKRs turn strategy into outcomes; opportunity solution trees find ways to move the outcomes; the matrix ranks the solutions; the roadmap sequences them; weekly notes and check-ins track progress.
