# Obsidian

## For future agent
This note describes Obsidian, a tool Company Brain depends on. Obsidian (https://obsidian.md) is the markdown editor Company Brain uses as its human interface: the vault is a plain folder; Dataview renders hub tables, Kanban renders boards, Templater fills templates, the graph view shows the brain colour-coded by layer.
